# Project Roadmap

This document outlines the high-level goals and upcoming milestones for this repository within the `train_service2` ecosystem.

## Current Status
- Transitioned to a unified Dual-License model (AGPLv3 / Commercial).
- Implemented global community standards (Code of Conduct, Contributing guidelines, Security policies).
- Integrated `graphify` and `codegraph` intelligence across all repositories.

## Short-term Goals
- **Standardized Testing**: Ensure the repository has fully automated Dockerized `pytest` execution scripts.
- **Code Coverage**: Automate code coverage calculation and reporting.
- **Documentation**: Keep the `README.md` strictly synchronized with the codebase capabilities and changelog.

## Mid-term Goals
- **Architecture Migration**: Follow WPipe integration rules where applicable to align with the ecosystem's standards.
- **Stability**: Enhance the reliability of the control server, invoker, and worker communication in the cluster.
- **End-to-End Validation**: Expand local testing scripts to simulate full UI requests prior to production rollout.

## Long-term Goals
- **Enterprise Deployments**: Streamline Docker builds and broadcasts for frictionless on-premise installations.
- **Advanced Autonomy**: Expand the capabilities of internal AI agents to handle complex data preparation and model training without human intervention.

*Note: This roadmap is a living document and may change as the ecosystem evolves.*
